Pela base de dados

O Gateway vai buscar as faturas diretamente à base de dados do sistema (por exemplo, o SQL Server do HOST). Só lê — nunca altera nada.

  • Não é preciso mexer no programa de faturação.
  • Precisa de alguém com acesso ao SQL Server (10 minutos).
Escolha esta se: o sistema guarda as faturas numa base de dados a que tem acesso (SQL Server, PostgreSQL, MySQL, Oracle…).
Ver o guia da base de dados

Por API

O próprio sistema envia cada fatura para o Gateway, pela internet ou pela rede, com uma chave secreta.

  • Não é preciso dar acesso à base de dados.
  • Precisa de quem programa o sistema (o fornecedor).
Escolha esta se: o fornecedor do seu ERP, POS ou loja online pode adicionar o envio das faturas.
