Ligar uma base de dados SQL Server

Em 7 passos simples, o Gateway passa a ler as faturas do seu sistema. Só lê: nunca apaga nem altera nada na sua base de dados.

Antes de começar, vai precisar de:

  • Alguém com acesso ao SQL ServerO técnico de informática ou o fornecedor do sistema.
  • SQL Server Management StudioO programa gratuito da Microsoft para gerir o SQL Server (SSMS).
  • Cerca de 10 minutosSó se faz uma vez.
1. Nome do servidor2. Nome da base3. Utilizador só de leitura 4. Modo de autenticação5. Rede (se preciso)6. Preencher no Gateway 7. Onde estão as faturasProblemas comunsOutros sistemas
1

Descobrir o nome do servidor

Abra o SQL Server Management Studio. Na primeira janela ("Connect to Server"), o nome do servidor aparece no campo Server name 1. Tome nota dele.

  • Se for só um nome (ex.: HOTEL-SRV), é a instância principal do computador.
  • Se tiver uma barra (ex.: HOTEL-SRV\SQLEXPRESS), escreva-o exatamente assim, com a barra.
  • Se o Gateway estiver instalado no mesmo computador do SQL Server, pode usar localhost.
2

Descobrir o nome da base de dados

Depois de entrar no SSMS, abra a pasta Databases à esquerda. Cada nome é uma base de dados.

Se houver várias e não souber qual é a do sistema de faturação, pergunte ao fornecedor do sistema (por exemplo, à HOST). Não adivinhe.
3

Criar um utilizador só de leitura para o Gateway

Por segurança, o Gateway entra com um utilizador próprio que só consegue ler. Há duas maneiras de o criar — escolha uma.

Maneira A — com o gerador (mais fácil)

Escreva o nome da base de dados, carregue em Gerar e copie o script. No SSMS, clique em New Query, cole o script e carregue em Execute (ou F5).

-- Escreva o nome da base de dados acima e carregue em "Gerar script e senha".
A senha é gerada no seu computador e não é enviada a lado nenhum. Guarde-a: vai precisar dela no passo 6. O script dá apenas permissão de leitura (db_datareader).

Maneira B — com cliques no SSMS

  1. Abra Security, clique com o botão direito em Logins e escolha New Login… 2
  1. Em Login name escreva gateway_leitura 3.
  2. Escolha SQL Server authentication, escreva uma senha forte duas vezes 4 e desmarque "User must change password at next login".
  1. À esquerda, abra User Mapping. Marque a base de dados do sistema 5.
  2. Em baixo, marque só db_datareader 6. Não marque db_datawriter nem db_owner. Carregue em OK.
4

Confirmar que o SQL Server aceita utilizadores com senha

No SSMS, clique com o botão direito no nome do servidor › Properties › Security. Tem de estar escolhido "SQL Server and Windows Authentication mode" 7.

5

Só se o Gateway estiver noutro computador: abrir a rede

Se o Gateway e o SQL Server estão no mesmo computador, salte este passo.

  1. Abra o SQL Server Configuration Manager e ative o TCP/IP 8.
  2. Reinicie o serviço "SQL Server".
  3. No Firewall do Windows do servidor, permita a porta 1433 apenas a partir do computador do Gateway.
6

Preencher no Gateway

No Gateway, vá a Ligações e carregue em Ligar base de dados.

Preencha assim:

7

Mostrar ao Gateway onde estão as faturas

Na página da ligação aparecem os passos que faltam. É aqui que o técnico (ou o fornecedor do sistema) indica em que tabelas estão as faturas.

  1. Explorar: mostra as tabelas e algumas linhas, para encontrar onde estão as faturas.
  2. Assistente: escolha a tabela das faturas e a das linhas, e em cada campo escolha a coluna certa da lista.
  3. Pré-visualizar: mostra as 3 primeiras faturas como vão ficar — sem importar nada.
  4. Guardar mapeamento e depois Sincronizar agora. As faturas aparecem em Faturas.

Outros sistemas de base de dados

O processo é igual: criar um utilizador só de leitura e preencher a ligação. Scripts de exemplo (substitua os nomes e a senha):

PostgreSQL

CREATE ROLE gateway_leitura LOGIN PASSWORD 'SenhaForte';
GRANT CONNECT ON DATABASE nome_da_base TO gateway_leitura;
GRANT USAGE ON SCHEMA public TO gateway_leitura;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO gateway_leitura;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO gateway_leitura;

MySQL / MariaDB

CREATE USER 'gateway_leitura'@'IP_DO_GATEWAY' IDENTIFIED BY 'SenhaForte';
GRANT SELECT ON nome_da_base.* TO 'gateway_leitura'@'IP_DO_GATEWAY';

Oracle

CREATE USER gateway_leitura IDENTIFIED BY "SenhaForte";
GRANT CREATE SESSION TO gateway_leitura;
-- Uma linha por tabela que o Gateway precisa de ler:
GRANT SELECT ON ESQUEMA.TABELA_FATURAS TO gateway_leitura;
